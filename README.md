# markeplace
моя задача написать проект - Маркетплейс драгоценных камней

минимальные возможности:
1) аутентификация и авторизация
2) каталог драгоценных камней
3) возможность пользователя добавить интересющий его драгоценный камень в корзину
4) заказать камни, добавленные в корзину, оплатить их


*Аутентификация и Авторизация - препдолагает с собой пользователей. Пользователей разделить на три группы: админ, зарегистрированный пользователь, гость. Роль админа заключается в том, что ему доступен весь функционал CRUD, кроме создания заказа и обхода оплаты. Зарегистрированному пользователю доступно CR, интерфейс взаимодействия с камнями и их заказом с оплатой. Гостю доступно только просмотр. Пользователь может зарегистрироваться по логину и паролю, логин уникальный, пароль не уникальный, почта опционально, но необязательно.

*Каталог драгоценных камней - препдолагает набор камней разных видов. Классификация камней будет по виду камня, цвету, структуре.

*Корзина - препдоплагает контейнер для камней у каждого пользователя, которые он добавил из каталога

*Заказ камней доступен только через коризну. Количество камней уменьшается только при оплате, добавление камня в корзину не уменьшает количество камней на стороне бд.
